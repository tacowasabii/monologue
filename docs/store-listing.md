## 설명

```
캡처해 둔 독백 대본, 사진첩에서 찾느라 헤매지 마세요.

모노로그는 대본 사진을 올리면 글자를 인식해 텍스트로 저장해 주는 연기 연습 노트예요.

■ 사진으로 바로 저장
사진첩에서 여러 장을 한 번에 고르거나 카메라로 찍으면, 순서대로 이어붙여 대본 하나로 만들어요. 인식한 글은 바로 고칠 수 있고, 원본 사진도 함께 보관해요.

■ 오디션 조건으로 찾기
작품명·성별·나이대·분위기 태그로 정리하고, 메모나 본문 한 구절로도 검색해요.

■ 대본을 이해하고 몰입하기
대화 장면은 인물별로 나눠 보여주고, 내 역할의 대사만 또렷하게 볼 수 있어요. 상황·원하는 것·가로막는 것 같은 분석 노트와 작품 줄거리·앞뒤 장면을 대본 옆에 적어 두고, 몰입 읽기 모드에서는 화면을 가득 채워 대본만 읽어요. 자주 보는 대본은 즐겨찾기로.

■ 내 폰에만 저장
로그인이 없고 대본이 외부로 전송되지 않아요. 글자 인식도 기기 안에서 처리해요. 폰을 바꿀 땐 백업 파일로 옮기면 돼요.
```

## 스크린샷 (촬영 목록)

1. 목록 화면 — 대본 여러 개, 태그가 보이게
2. 대화 대본 보기 — 내 역할 강조가 보이게
3. 몰입 읽기 화면
4. 대본 노트(분석·작품 맥락) 화면
5. 사진 선택 후 순서 정렬 화면

크기: iPhone 6.9"(1320×2868), Android 폰 세로. 샘플 대본은 저작권이 없는 자작 문장만 사용.
