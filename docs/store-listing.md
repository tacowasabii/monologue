## 설명

```
캡처해 둔 독백 대본, 사진첩에서 찾느라 헤매지 마세요.

모노로그는 대본 사진을 올리면 글자를 인식해 텍스트로 저장해 주는 연기 연습 노트예요.

■ 사진으로 바로 저장
사진첩에서 여러 장을 한 번에 고르거나 카메라로 찍으면, 순서대로 이어붙여 대본 하나로 만들어요. 인식한 글은 바로 고칠 수 있고, 원본 사진도 함께 보관해요.

■ 오디션 조건으로 찾기
작품명·성별·나이대·분위기 태그로 정리하고, 메모나 본문 한 구절로도 검색해요.

■ 대본을 이해하고 몰입하기
대화 장면은 인물별로 나눠 보여주고, 내 역할의 대사만 또렷하게 볼 수 있어요. 인물의 상황이나 떠오르는 생각은 정해진 칸 없이 노트에 자유롭게 적어 두고, 몰입 읽기 모드에서는 화면을 가득 채워 대본만 읽어요. 자주 보는 대본은 즐겨찾기로.

■ 내 폰에만 저장
로그인이 없고 대본이 외부로 전송되지 않아요. 글자 인식도 기기 안에서 처리해요. 폰을 바꿀 땐 백업 파일로 옮기면 돼요.
```

## 개인정보 라벨

### App Store

- "앱 개인정보 보호": **데이터를 수집하지 않음**. iPhone은 글자 인식에 Apple Vision을 쓰고, 외부로 데이터를 보내는 SDK가 없다.
- 사용 설명(Info.plist): 카메라(대본·연습 영상 촬영), 마이크(연습 녹음), 사진(캡처·영상 불러오기).

### Google Play 데이터 보안

Android 앱에 들어 있는 Google ML Kit(글자 인식)가 진단 정보를 Google로 보내므로 **"수집함"** 으로 답한다. 대본·사진·노트·녹음은 기기 밖으로 나가지 않는다. 근거: [ML Kit Android 데이터 공개](https://developers.google.com/ml-kit/android-data-disclosure) — 기기 정보, 앱 버전, 설치별 식별자, 성능 지표, 이벤트·오류 코드를 HTTPS로 보내고 제3자에게 넘기지 않으며, 끄는 방법은 안내돼 있지 않다.

| 질문 | 답 |
|---|---|
| 필수 사용자 데이터 유형을 수집하거나 공유하나요? | 예 |
| 수집하는 데이터는 모두 전송 중 암호화되나요? | 예 (HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 아니요 (개발자가 보관하는 데이터가 없음) |

| 데이터 유형 | 수집 | 공유 | 사용자가 거부 가능 | 목적 |
|---|---|---|---|---|
| 앱 정보 및 성능 → 진단 | 예 | 아니요 | 아니요 (필수) | 분석 |
| 기기 또는 기타 ID → 기기 또는 기타 ID | 예 | 아니요 | 아니요 (필수) | 분석 |

제출 전에 Play Console의 데이터 유형 설명과 위 ML Kit 안내가 바뀌지 않았는지 다시 확인한다.

### 권한 (Android 릴리스 빌드 기준)

- `RECORD_AUDIO`: 연습 녹음할 때만
- `INTERNET`, `ACCESS_NETWORK_STATE`: ML Kit 진단 정보 전송 라이브러리(`datatransport`)와 미디어 재생 라이브러리가 추가
- 카메라·사진·파일은 시스템 카메라 앱, 사진 선택기, 파일 선택기를 거쳐서 권한을 따로 요청하지 않는다
- 개인정보처리방침: https://tacowasabii.vercel.app/monologue/privacy (ML Kit 진단 정보 설명 포함)
