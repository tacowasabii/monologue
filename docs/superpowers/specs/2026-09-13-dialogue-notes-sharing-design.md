# 모노로그 — 대화 대본 · 몰입 읽기 · 대본 노트 · 1:1 공유 설계

작성일: 2026-09-13 · 상태: 공유를 뺀 나머지 구현됨 (제목·인물 칸을 메모로 바꾼 `main` 79532b0 기준). 1:1 공유는 파일 전송보다 편한 방식으로 다시 설계하기로 해서 보류 — 표의 `1:1 공유`·`공유 파일 형식`·`받기` 행과 `파일에서 가져오기` 이름 변경은 아직 적용되지 않았다

## 목적

배우가 대본을 **이해하고 몰입**하도록 돕는다. 암기 보조, 진도 관리, 입시 준비 기능은 범위에 넣지 않는다.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 대본 이름 | 대본에는 제목·인물 칸이 없다. 화면에 보이는 대본 이름은 목록 카드와 같은 규칙인 `작품명`, 없으면 본문 첫 줄이다 |
| 대본 형식 | 대본마다 `독백` / `대화` 중 하나를 고른다. 앱 전체 설정은 두지 않는다. 본문은 계속 평문 한 덩어리로 저장한다 |
| 형식 기본값 | 새 대본은 본문에 `이름:` 형태의 줄이 2줄 이상이면 `대화`, 아니면 `독백`으로 시작한다. 기존 대본은 `독백` |
| 대사 인식 규칙 | 줄 시작이 `이름: 대사`(콜론 앞뒤 공백 허용, 전각 `：` 허용). 이름은 1~12자이며 숫자만으로 된 이름과 `http`로 시작하는 이름은 대사로 보지 않는다. 이름 없는 줄은 빈 줄이 나올 때까지 앞 인물의 대사로 이어진다. 줄 전체가 괄호 `(…)`이면 지문이다. 빈 줄 뒤에 이름 없이 오는 줄은 지문으로 본다 |
| 내 역할 | `대화` 대본을 볼 때 인물 칩 중 하나를 고르면 그 인물 대사는 또렷하게, 나머지 대사는 흐리게 보인다. 고른 역할은 대본마다 저장되고(칩을 누르는 즉시), 다시 누르면 해제된다. 고른 적 없으면 강조하지 않는다 |
| 몰입 읽기 | 보기 화면의 `몰입 읽기` 버튼으로 들어간다. 상태 표시줄을 숨긴 전체 화면이고, 읽는 동안 화면이 꺼지지 않는다. 화면을 탭하면 닫기와 글자 크기 버튼이 나타난다. 맨 위에 대본 이름과 `상황` 노트를 보여준다. 내 역할 강조가 그대로 적용된다 |
| 대본 노트 — 분석 | 상황(누가·어디서·언제·직전에 무슨 일), 원하는 것, 가로막는 것. 모두 선택 입력. 자유 메모는 기존 `메모` 칸을 쓴다 |
| 대본 노트 — 작품 맥락 | 작가, 매체(영화·드라마·연극·뮤지컬·창작·기타), 출처 링크, 작품 줄거리, 이 장면 앞뒤. 모두 선택 입력 |
| 노트 편집·표시 | 보기 화면의 `노트` 버튼으로 여는 별도 화면에서 편집하고 `저장`으로 반영한다. 편집 화면(작품명·메모 중심)은 늘리지 않는다. 보기 화면에는 `상황`이나 `원하는 것`이 있을 때 본문 위에 요약 카드를 보여준다 |
| 글 표시 | 보기·몰입 읽기·요약 카드의 한국어 글은 기존 `keepWords`로 띄어쓰기에서만 줄을 바꾸고, 복사할 때는 보이지 않는 문자를 뺀다 |
| 검색 | 기존 대상(작품명·메모·본문)에 `작가`를 더한다 |
| 1:1 공유 | 보기 화면 메뉴의 `공유하기`로 대본 하나를 `<대본 이름>.monologue` 파일로 만들어 시스템 공유 시트로 보낸다. 원본 사진은 기본 제외이고, 공유 창에서 포함을 켤 수 있다 |
| 공유 파일 형식 | 백업과 같은 zip(`backup.json` + `images/`)에 대본 1개를 담는다. 확장자만 `.monologue` |
| 받기 | ① 카카오톡·파일 앱 등에서 `.monologue` 파일을 모노로그로 연다(iOS 문서 타입, Android VIEW/SEND 인텐트). ② 설정의 `파일에서 가져오기`(기존 `백업에서 복원`을 대체, `.zip`·`.monologue` 모두 받음). 가져오기 전에 확인하고, 대본 하나를 받았으면 끝난 뒤 그 대본을 연다. 항상 새 대본으로 추가한다 |
| 백업 형식 | version 2. 대본 항목에 `dialogue`(bool), `myRole`, `notes`(객체)를 더한다. version 1 백업도 계속 복원한다(`dialogue`=false, 역할·노트 없음) |
| DB | schemaVersion 6 (main의 4: 모음, 5: 연습 기록 다음). `scripts`에 `dialogue` bool(기본 false), `my_role`, 노트 컬럼 8개(nullable text, `medium`은 enum 이름)를 추가한다. 버전 3~5에서 올라오면 컬럼만 더해 대본·모음·연습 기록을 유지하고, 1·2는 기존 규칙대로 비우고 다시 만든다 |
| 사용 방법 화면 | 설정 → 사용 방법에 대화 대본·대본 노트·몰입 읽기·대본 공유 항목을 더하고, 백업 항목의 `백업에서 복원`을 `파일에서 가져오기`로 고친다 |
| 개인정보 | 서버 전송 없음 유지. 스토어 개인정보 표시 "데이터를 수집하지 않음" 유지. 새 권한 없음 |
| 연습 상태 | UI에서는 이미 제거됨. DB 컬럼·백업 필드는 그대로 둔다 |
