# 모노로그 디자인 시스템

앱 화면을 만들거나 고칠 때 따르는 규칙이다. 코드는 `lib/ui/design/`(화면에서는 `design.dart` 하나를 가져온다), 색과 글꼴은 `lib/ui/theme.dart`에 있다.
새 창이나 시트를 만들 때 `AlertDialog`, `showModalBottomSheet`를 바로 쓰지 않고 아래 부품을 쓴다.

## 바탕

- **분위기**: 종이 대본 노트. 따뜻한 미색 바탕(`surface`), 먹색 글자(`onSurface`), 포인트는 자주색(`primary`, `brandPlum`).
- **색**: 화면에 색 값을 직접 쓰지 않고 `Theme.of(context).colorScheme`에서 꺼낸다. 밝은·어두운 화면이 같은 이름의 색을 쓴다.
  - 즐겨찾기 별은 `favoriteColor(scheme)`(금색)
  - 되돌릴 수 없는 동작은 `error`
- **글꼴**: 제목과 대본 본문은 명조(`serifFamily`, 고운바탕), 나머지는 시스템 고딕. `titleLarge` 이상은 테마에서 이미 명조다.
- **말투**: 해요체. 버튼은 동사로 짧게(만들기, 삭제, 내보내기), 제목은 묻는 문장(대본 2편을 삭제할까요?).

## 모서리·간격 (`tokens.dart`)

| 이름 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `AppRadius.small` | 12 | 아이콘 상자, 스낵바, 세그먼트 버튼 |
| `AppRadius.medium` | 16 | 버튼, 입력칸, 검색창, 시트 항목 |
| `AppRadius.large` | 20 | 카드 |
| `AppRadius.dialog` | 24 | 가운데 창 |
| `AppRadius.sheet` | 28 | 아래 시트 위 모서리 |

- **간격**: `AppSpace.xs 4 · sm 8 · md 12 · lg 16 · xl 24 · xxl 32`
- **화면 좌우 여백**: `AppSpace.page`(20)
- **목록 아래 여백**: 떠 있는 버튼이 있는 목록은 `AppSize.fabClearance`(112)만큼 둔다.

## 버튼 (`app_action.dart`)

`AppAction(라벨, kind:, onPressed:)`를 만들어 `AppDialog`나 `AppActionBar`에 넘긴다.

| kind | 모양 | 쓰는 곳 |
| --- | --- | --- |
| `primary` | 채움 | 가장 권하는 동작. 한 곳에 하나 |
| `destructive` | 경고색 채움 | 삭제·버리기·저장 안 하고 나가기 |
| `secondary` | 외곽선 | 취소, 다른 선택지 |
| `quiet` | 글자만 | 버튼이 셋 이상일 때 맨 아래 취소 |

- `onPressed: null`이면 흐리게 보이고 누를 수 없다. 입력이 맞지 않을 때는 버튼을 막고, 이유는 입력칸 아래 `errorText`로 알린다.

## 가운데 창 (`AppDialog`)

사용자가 멈추고 답해야 할 때만 쓴다.

- **구성**: 제목 → 설명(`message`) → 필요하면 입력칸·체크 같은 `content` → 넓은 버튼
- **버튼 둘**: 가로로 나눠 갖는다. 왼쪽 `secondary`(취소), 오른쪽 `primary`/`destructive`.
- **버튼 셋 이상**: 세로로 쌓는다. 위에서부터 권하는 동작 → 다른 선택지 → `quiet` 취소.
- **확인만 받을 때**: `showConfirmDialog(title:, message:, confirmLabel:, destructive:)`
- **지우기 확인**: 무엇이 함께 사라지는지 설명에 적는다(원본 사진과 연습 기록도 함께 지워져요).
- **진행 중 창**(글자 읽는 중)은 버튼 없이 `content`에 진행 막대를 두고, 창 밖을 눌러도 닫히지 않게 한다.

## 아래 시트 (`app_sheet.dart`)

여러 선택지 중 하나를 고르거나, 화면을 떠나지 않고 설정을 바꿀 때 쓴다.

- **선택지를 고를 때**: `showAppSheet(title:, subtitle:, children:)`에 `AppSheetTile`을 넣는다.
  - 항목은 아이콘 상자 + 이름 + 설명 한 줄.
  - 지우기 항목은 `destructive: true`로 경고색을 쓰고, 화살표를 뺀다.
  - 누르면 바로 다음 단계로 간다. 지우기 항목도 시트에서 끝내지 않고 확인 창을 한 번 더 띄운다.
- **내용을 직접 그리는 시트**(글자 크기, 필터, 대화 미리보기): 맨 위를 `AppSheetHeader`로 시작한다. 오른쪽 버튼(초기화)은 `trailing`에 둔다.

## 알림 (SnackBar)

- 끝난 일을 짧게 알린다. 예: 대본 2편을 삭제했어요, 저장하지 못했어요. 다시 시도해 주세요.
- 결정을 묻는 데 쓰지 않는다.

## 추가 버튼

- 탭 화면의 새 항목 만들기는 오른쪽 아래에 떠 있는 검은 버튼(`FloatingActionButton.extended`)으로 둔다. 예: 대본 탭 "대본 추가", 모음 탭 "새 모음".
- 목록 칸 안에 "새로 만들기" 카드를 섞지 않는다.
- 두 탭이 한 화면에 함께 살아 있으므로 모음 탭 버튼은 `heroTag: null`로 둔다.
- 편집 화면처럼 그 자리에서 바로 고르는 곳은 칩("+ 새 모음")을 쓴다.

## 목록 편집 모드

- **들어가기**: 대본 카드를 길게 누른다. 누른 카드가 골라진 채로 시작한다.
- **위 막대**: 닫기(편집 끝내기), "N편 선택", 모두 선택/선택 해제
- **카드**
  - 누르면 열지 않고 고른다.
  - 오른쪽 별 자리에 선택 동그라미가 온다.
  - 모음 안에서는 ≡ 손잡이가 함께 나오고, 손잡이를 끌어 순서를 바꾼다.
  - 편집 모드 밖에서는 순서를 바꾸지 않는다.
- **아래 막대**(`AppActionBar`)
  - 모음 안: `secondary` 모음에서 빼기 + `destructive` 삭제
  - 그 밖: 삭제만
  - 고른 게 없으면 버튼을 막는다.
- **확인**
  - 삭제는 확인 창을 거친다.
  - 모음에서 빼기는 대본이 남아서 묻지 않고 알림으로 알린다.
- **나가기**: 뒤로 가기를 누르면 화면을 닫지 않고 편집 모드만 끝낸다.
- 모음·연습 기록처럼 한 번에 하나만 다루는 곳은 길게 누르면 관리 시트나 확인 창을 띄운다.
